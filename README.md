# Chrissy Bales — Homepage Redesign Concept

A modern, sleek redesign concept for [chrissybales.com](https://chrissybales.com).

## What this is
A static HTML mockup proposing a full visual and structural redesign of the Chrissy Bales homepage. Built to demonstrate direction before any real Shopify build.

## What it tackles
- Clearer hero value proposition (specific, not poetic)
- Trust signals visible above the fold
- Founder story on the homepage
- Social proof with real-feel testimonials
- Price anchoring on collection tiles
- Streamlined 4-item navigation (down from 6)
- Quiz CTA to capture warm leads
- Cleaner mobile experience

## What's clickable
Nothing — this is a visual mockup only. Buttons and menus are decorative. The cart, account, and search icons don't function. All product images are stock placeholders.

## Caveats
- All testimonials are illustrative and need real client quotes
- Stat claims ("2,400+ clients", "5+ year lifespan", "4-week craft time") are placeholders to be verified
- Prices shown are guesses, not real product anchors
- Stock photography to be replaced with actual brand imagery

## Tech
Single self-contained HTML file. No build step. Loads fonts from Google Fonts and icons from jsDelivr CDN.
